# platform/dev-seed-data Specification

## Purpose

로컬 개발과 데모에서 실제 작은도서관과 비슷한 규모의 더미 데이터(기관, 계정, 도서, 사본, 회원, 대출)를 한 번에 채워, API와 이후 에이전트를 실데이터 없이 확인할 수 있게 한다.

## Requirements

### Requirement: 시드 데이터 생성
시드 스크립트는 마이그레이션이 적용된 DB에 다음 데이터를 SHALL 생성한다.
- **기관 2곳**: 하나는 운영 방식 `internal`, 하나는 `imported`
- **직원 계정**: 기관마다 관리자 1개, 키오스크 1개. 비밀번호는 `.env`의 시드 비밀번호로 정한다.
- **도서 50권** (기관 공통)
  - 일부는 어린이 도서(`children`)다.
  - 일부는 ISBN과 정가가 없는 기증 도서다.
- **사본**: 기관마다 도서 일부의 사본을 만든다.
  - 같은 책 여러 권, 소장하지 않은 책, 분실·훼손 사본이 모두 있게 한다.
  - 매입·납품 사본과 기증 사본이 모두 있게 한다.
- **회원**: 기관마다 회원을 만든다.
- **대출**: 자체 대출 기관에만 만든다.
  - 반납된 것, 대출 중인 것, 연체된 것이 모두 있게 한다.

#### Scenario: 빈 DB에 시드 실행
- **WHEN** 빈 DB에 마이그레이션 후 시드 스크립트를 실행하면
- **THEN** 다음이 생긴다
  - libraries 2건 (운영 방식 2가지)
  - staff_users 4건 (기관마다 admin·kiosk)
  - books 50건 (어린이 도서 1건 이상, ISBN 없는 도서 1건 이상)
  - 두 기관 모두 holdings 1건 이상, 매입·납품 사본과 기증 사본이 각각 1건 이상
  - 자체 대출 기관에만 loans가 있고, 연체 대출이 1건 이상이다

#### Scenario: 시드 데이터가 도메인 규칙을 지킴
- **WHEN** 시드 스크립트를 실행한 뒤 데이터를 확인하면
- **THEN** 다음이 모두 성립한다
  - ISBN이 있는 도서의 ISBN은 모두 체크 디지트가 올바른 13자리 숫자다.
  - 정가와 구입가는 있으면 모두 0 이상의 정수다.
  - 매입·납품 사본은 모두 구입가가 있고, ISBN이 있는 도서를 가리킨다.
  - 대출 중인 사본의 상태는 `on_loan`이다.
  - 시드 계정으로 로그인할 수 있다.

### Requirement: 반복 실행 안전성
시드 스크립트는 여러 번 실행해도 데이터를 중복 생성하지 않아야 MUST 한다. 같은 시드 값으로 실행하면 같은 데이터가 만들어진다.

#### Scenario: 두 번 실행
- **WHEN** 시드 스크립트를 연속으로 두 번 실행하면
- **THEN** 모든 테이블의 건수가 첫 실행 후와 같다

### Requirement: 실행 전제 조건 확인
시드 스크립트는 데이터를 쓰기 전에 DB 연결과 마이그레이션 상태를 확인 MUST 한다. 전제 조건이 맞지 않으면 아무 데이터도 쓰지 않고, 원인과 해결 방법을 알려 주는 한 줄 메시지를 stderr에 출력한 뒤 0이 아닌 종료 코드로 끝난다. 스택 트레이스는 출력하지 않는다. 성공하면 종료 코드는 0이다.

#### Scenario: 마이그레이션 전 실행
- **WHEN** 테이블이 없는(마이그레이션을 적용하지 않은) DB에서 시드 스크립트를 실행하면
- **THEN** `alembic upgrade head`를 먼저 실행하라는 메시지를 출력하고 0이 아닌 종료 코드로 끝나며, DB에는 아무 데이터도 생기지 않는다

#### Scenario: 마이그레이션이 최신이 아님
- **WHEN** 마이그레이션 리비전이 최신(head)보다 뒤처진 DB에서 시드 스크립트를 실행하면
- **THEN** `alembic upgrade head`를 실행하라는 메시지를 출력하고 0이 아닌 종료 코드로 끝나며, 데이터를 쓰지 않는다

#### Scenario: DB에 연결할 수 없음
- **WHEN** DB가 꺼져 있거나 `DATABASE_URL`이 잘못된 상태에서 시드 스크립트를 실행하면
- **THEN** 접속 대상(호스트, 포트, DB 이름)과 `docker compose up -d db` 안내를 담은 메시지를 출력하고 0이 아닌 종료 코드로 끝난다. 메시지에 비밀번호는 포함하지 않는다

#### Scenario: 정상 실행
- **WHEN** 마이그레이션이 최신인 DB에서 시드 스크립트를 실행하면
- **THEN** 생성·건너뛴 건수를 출력하고 종료 코드 0으로 끝난다
