## Why

서버 쪽 관리 기능(운영 에이전트 대화, 큐레이션·연체 안내문 틀·구매 요청서의 승인, 희망도서 목록, 오늘의 연체 안내)은 모두 REST로 되지만 관리자 화면이 없어 Swagger로만 쓸 수 있다. 이용자 화면은 개발용 `#token=`으로만 열리고 로그인 화면이 없다. 공용 PC 이용자 화면은 무입력 4분 30초 뒤에 말없이 비워지고, 한 사람이 화면을 오래 붙잡는 것을 막지 못한다. MVP 출시 전에 "키오스크가 로그인으로 시작하고, 관리자 승인까지 화면으로 동작"하는 상태가 필요하다.

서버를 바꾸지 않는 화면 일만 이 change에서 한다. 분석 답의 표·차트 사건(서버와 `agent/admin` 스펙 변경), 장서 가져오기 화면, 운영 평가 전체 회귀는 다음 change(24b, 가칭 `add-admin-analytics-ui`)로 나눈다.

## What Changes

- **로그인 화면** `/ui/login/`: 키오스크와 관리자가 함께 쓴다. `POST /auth/login`의 역할로 행선지를 정한다(키오스크 → `/ui/librarian/`, 관리자 → `/ui/admin/`).
  - 토큰은 화면마다 키 하나다. 키오스크 토큰은 `localStorage`(PC를 다시 켜도 이어짐), 관리자 토큰은 `sessionStorage`(탭을 닫으면 사라짐)에 둔다. 관리자가 같은 공용 PC에서 로그인해도 키오스크 토큰을 덮어쓰지 않는다.
  - 각 화면은 열 때 `GET /auth/me`로 역할을 확인한다. 토큰이 없거나, 401이거나, 역할이 다르면 그 화면의 키를 지우고 로그인 화면으로 보낸다.
  - 관리자 화면에만 [로그아웃](`POST /auth/logout`)이 있다. 이용자 화면에는 로그아웃 버튼을 두지 않는다.
  - **BREAKING**(개발용): 이용자 화면의 `#token=` 받기와 `chaekbang.token` 키를 없앤다. 이미 켜 둔 키오스크는 한 번 다시 로그인한다.
- **이용자 화면 비우기 규칙**: 무입력 4분 30초를 다음 둘로 바꾼다.
  - 무입력 1분이면 비운다. 45초에 알림을 띄우고, 입력하면 알림을 닫고 다시 센다.
  - 이용 시작(빈 화면에서 첫 입력)부터 3분이면 무조건 비운다. 2분 30초에 알림을 띄우고 연장하지 않는다. 답을 받는 중이어도 끊는다.
  - 알림은 화면 아래 띠(문구, 남은 초)다. 서버 AI 사서 세션(5분)보다 늘 먼저 비운다.
  - 시간이 다 돼 비우면 시작 화면("화면을 눌러 시작하세요")을 보이고 누르면 대화 화면으로 간다. 처음 열 때도 시작 화면이다. 키오스크는 로그아웃하지 않는다. [새 대화]는 시작 화면 없이 비운다.
- **관리자 화면** `/ui/admin/`: 빌드 없는 정적 파일 한 페이지에 탭 넷(운영 대화, 승인 목록, 희망도서, 오늘의 연체)을 둔다. 탭은 주소 hash로 기억한다. 720px 아래에서는 한 줄로 쌓는다.
  - **운영 대화**: 지금의 SSE 사건(`session`·`status`·`answer`·`done`) 그대로, 답 문장만 글자로 보인다. `unsupported` 표시, [새 대화], 세션 만료 안내를 둔다. 답이 끝나면 승인 대기 수를 다시 세어 탭에 보인다.
  - **승인 목록**: 큐레이션, 연체 안내문 틀, 구매 요청서 세 묶음이다. 기본은 승인 대기만 보인다. 상세를 보고 승인(확인 한 번)·반려(사유 필수)를 하고, 게시한 큐레이션은 내린다. 구매 요청서 상세는 추정 금액·가격 없음·조회 불가를 보이고, 확정본은 기록한 금액을 보인다. 승인의 409·503은 서버 문구를 그대로 보인다. 만들기·고치기 양식은 두지 않는다(초안은 운영 대화로 만든다).
  - **희망도서**: 처리 전 목록(회원번호 포함), [더 보기], [닫기].
  - **오늘의 연체**: `GET /overdue-notices/today`의 줄(회원번호·이름·전화·서명·등록번호·반납 예정일·연체 일수·문안). 확정한 틀이 없을 때(409)는 안내한다.
  - 외부 대출 기관(`loan_mode = external`)에서는 [오늘의 연체] 탭과 승인 목록의 연체 안내문 틀 묶음을 숨긴다. 서버 409가 방어선이다.
  - 회원 값이 보이는 탭(희망도서, 오늘의 연체)은 들어올 때마다 서버에서 다시 불러온다. 로그아웃한 뒤 [뒤로]로 돌아오면 토큰을 다시 확인한다.
- **API**: 새 경로는 없다. 화면은 기존 REST만 부른다.
- **범위 밖**(design의 미룰 것): 표·차트 사건과 분석 REST, 장서 가져오기 화면, 운영 평가 회귀(24b), 담은 책 이어 보기(24c, 가칭 `add-basket-resume`), 이용자 화면의 "이달의 추천" 줄, 초안 고치기 화면, 관리자 무입력 자동 로그아웃, 브라우저 자동화 테스트(Playwright).

### New Capabilities

(없음)

### Modified Capabilities

- `platform/web-ui`: 로그인·관리자 화면 내주기, 화면별 토큰 저장과 역할 확인, 이용자 화면의 무입력·이용 상한 비우기와 알림, 관리자 화면이 부르는 경로, 운영 대화 요청 본문, 승인 목록 동작, 운영 방식에 따른 연체 화면, 관리자 화면의 회원 값 다루기. "기존 API만 사용", "브라우저 저장", "서버 값의 안전한 표시"의 범위를 관리자·로그인 화면까지 넓힌다
