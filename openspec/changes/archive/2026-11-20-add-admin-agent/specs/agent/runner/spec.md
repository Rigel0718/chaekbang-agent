## ADDED Requirements

### Requirement: 최종 답의 기록 필드
최종 답 tool은 실행 기록에 남겨도 되는 답 필드를 SHALL 고를 수 있다. 실행이 검사를 통과한 답이나 정리한 답으로 끝나면 실행기는 그 답의 고른 필드 값만 실행 행에 남긴다. 고르지 않았거나 고정 답·실패·중단으로 끝나면 남기지 않는다. 고르지 않은 필드(문장 등)는 남기지 않는다.

#### Scenario: 고른 필드만
- **WHEN** 문장과 `kind` 필드 중 `kind`만 고른 최종 답 tool로 실행이 끝나면
- **THEN** 실행 행의 답 기록에는 `kind`만 있고 문장은 실행과 단계 행 어디에도 없다

#### Scenario: 고르지 않은 tool
- **WHEN** 기록 필드를 고르지 않은 최종 답 tool로 실행이 끝나면
- **THEN** 실행 행의 답 기록은 비어 있다

#### Scenario: 고정 답
- **WHEN** 기록 필드를 고른 프로필의 실행이 고정 답으로 끝나면
- **THEN** 실행 행의 답 기록은 비어 있고 상태는 `fallback`이다
