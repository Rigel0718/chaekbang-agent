## 2. 화면 문구 (Sonnet, 마크업·스크립트·문서)

- [x] 2.1 `shared/api.js`에 `GENERIC_ERROR = "잠시 뒤 다시 해 주세요."`를 내보내고, 문구 없는 실패의 기본 메시지에 쓴다(상태 번호 없음). 각 화면 파일의 일반 실패 상수와 [담기] 실패 문구를 이것으로 바꾼다. [승인 목록] 503 갈래의 덧붙임을 없애고, [오늘의 연체]는 서버 문구 뒤에 "[AI 도우미]로 양식을 만들어 승인해 주세요."를 한 번 붙인다(design 결정 1, 7)
- [x] 2.2 로그인 화면: 문서 제목과 큰 제목을 "직원 로그인"으로 바꾼다
- [x] 2.3 이용자 화면

  - 기다리는 문구 "살펴보는 중…", [AI 사서에게 묻기]

- [x] 2.4 관리자 화면

  - **도서명**: 칸 이름·찾기 칸 안내·표 머리글·오류 문구의 서명 → 도서명. 사본 → 책, 소장 권수 → 권수, 장서 → 책 목록, "이용 가능" → "대출 가능"

    - 연체 안내 양식 묶음 이름과 문구, "승인한 뒤에는 수정할 수 없어요."

  - **AI 도우미**: "지금은 못 하는 분석이에요."
- [x] 2.5 화면 검사 테스트를 `tests/platform/test_ui_copy.py`에 더한다. 확인: web-ui delta의 소스 검사 시나리오마다 테스트

  - 그리고 `tests/platform/test_web_ui.py`의 기존 문구 검사(10권 상한·[담기] 실패)를 새 문구로 고친다
