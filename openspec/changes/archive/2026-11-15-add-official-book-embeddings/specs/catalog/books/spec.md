## MODIFIED Requirements

### Requirement: 공식 서지 쓰기 제한
공식 서지(`books`)는 ISBN이 있는 책의 서지정보만 SHALL 보관하고, 운영자가 실행하는 서지정보 채움과 실험 장서 적재만 만든다. 두 경로는 같은 규칙으로 공식 서지를 만든다(외부 값만 쓰고, 이미 있는 공식 서지는 고치지 않고, 기여자와 시리즈 키를 함께 만든다). 기관 관리자와 키오스크가 쓰는 API에는 공식 서지를 만들거나 고치거나 지우는 경로를 MUST NOT 둔다. 기관의 파일 값과 입력 값은 공식 서지에 들어가지 않는다.

#### Scenario: 도서 API 경로 없음
- **WHEN** 관리자가 `POST /books`, `PATCH /books/{id}`, `DELETE /books/{id}`를 호출하면
- **THEN** 404를 돌려주고 공식 서지는 바뀌지 않는다

#### Scenario: 기관 도서 등록은 공식 서지를 만들지 않음
- **WHEN** 관리자가 공식 서지에 없는 ISBN으로 기관 도서를 등록하면
- **THEN** books 행은 늘어나지 않는다

#### Scenario: 두 경로의 같은 결과
- **WHEN** 같은 외부 응답 상품 하나를 서지정보 채움과 실험 장서 적재로 각각 빈 DB에 넣으면
- **THEN** 만들어진 공식 서지의 서지 값, 기여자, 시리즈 키가 서로 같다

## ADDED Requirements

### Requirement: 시리즈 키
시스템은 공식 서지를 만들 때 외부 응답의 시리즈 목록에서 시리즈마다 이름 맞춤 키를 계산해 목록으로 MUST 저장한다. 시리즈를 한 문자열로 잇기 전의 목록에서 계산하고, 키가 비는 시리즈와 중복은 뺀다. 시리즈가 없으면 빈 목록이다. 표시용 시리즈명은 그대로 둔다.

#### Scenario: 시리즈 여러 개
- **WHEN** 응답의 시리즈가 `민들레그림책`과 `우리 그림책` 두 개이면
- **THEN** 시리즈 키는 `민들레그림책`, `우리그림책` 두 개이고 시리즈명은 `민들레그림책, 우리 그림책`이다

#### Scenario: 쉼표가 든 시리즈명
- **WHEN** 응답의 시리즈가 `읽고, 쓰고, 생각하고` 하나이면
- **THEN** 시리즈 키는 `읽고쓰고생각하고` 하나다

#### Scenario: 시리즈 없음
- **WHEN** 응답에 시리즈가 없으면
- **THEN** 시리즈 키는 빈 목록이다

#### Scenario: 표기가 다른 같은 시리즈
- **WHEN** 한 공식 서지의 시리즈가 `Why? 과학`이고 다른 공식 서지의 시리즈가 `WHY 과학`이면
- **THEN** 두 공식 서지의 시리즈 키에 같은 값이 있다
