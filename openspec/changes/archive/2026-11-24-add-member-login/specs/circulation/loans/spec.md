# Spec Delta

## MODIFIED Requirements

### Requirement: 대출하기
키오스크나 관리자는 등록번호와 회원 세션으로 자기 기관의 사본을 SHALL 대출할 수 있다.
- 요청: `POST /loans`에 등록번호만 담는다. 빌리는 회원은 회원 로그인으로 받은 회원 세션(`X-Member-Token`)에서 정하고 본문의 회원번호는 받지 않는다.
- 회원 세션이 없거나 끝났으면 403이다.
- 대출일: 기관 시간대 기준 오늘
- 반납 예정일: 도서관 안내의 반납 예정일 계산을 따른다. 대출일 + 기관의 기본 대출 기간이고, 그날이 휴관이면 기관의 반납일 휴관 규칙을 따른다. 휴관 정보(운영 시간, 공휴일 휴관, 임시 휴관일)를 하나도 등록하지 않은 기관은 대출일 + 기본 대출 기간이다.
- 대출하면 사본 상태가 `on_loan`이 된다.

#### Scenario: 정상 대출
- **WHEN** 기본 대출 기간이 14일인 자체 대출 기관에서 회원이 로그인한 뒤 `available` 사본의 등록번호로 `POST /loans`를 호출하면
- **THEN** 201과 함께 반납 예정일이 오늘부터 14일 뒤인 대출을 돌려주고, 사본 상태는 `on_loan`이며 대출의 회원은 로그인한 회원이다

#### Scenario: 휴관일로 떨어진 반납 예정일
- **WHEN** 반납일 휴관 규칙이 `next_open_day`이고 14일 뒤가 임시 휴관일인 자체 대출 기관에서 대출하면
- **THEN** 반납 예정일은 그다음 개관일이고 같은 날 안내 조회의 오늘 빌리면 반납 예정일과 같다

#### Scenario: 없는 회원번호
- **WHEN** 회원 토큰 없이 본문에 회원번호만 넣어 `POST /loans`를 호출하면
- **THEN** 403을 돌려주고 사본 상태는 바뀌지 않는다

#### Scenario: 끝난 회원 세션
- **WHEN** 로그인에서 3분이 지난 회원 토큰으로 `POST /loans`를 호출하면
- **THEN** 403을 돌려주고 사본 상태는 바뀌지 않는다

#### Scenario: 본문의 회원번호는 쓰지 않음
- **WHEN** 본문에 다른 회원의 `member_number`를 넣고 로그인한 회원 토큰으로 대출하면
- **THEN** 대출은 로그인한 회원의 것이고 본문의 회원번호는 무시된다

#### Scenario: 다른 기관의 등록번호
- **WHEN** 다른 기관에만 있는 등록번호로 대출하면
- **THEN** 404를 돌려준다

#### Scenario: 외부 대출 기관은 로그인해도 대출하지 않음
- **WHEN** 운영 방식이 `external`인 기관에서 회원이 로그인한 뒤 `POST /loans`를 호출하면
- **THEN** 409를 돌려주고 대출은 만들어지지 않는다
