# Spec Delta

## MODIFIED Requirements

### Requirement: 저장 내용
`chat_messages`에는 가린 이용자 문장과 최종 답만 MUST 저장한다. 고른 책이나 찾은 책이 있으면 그 이용자 행의 책 표시 칸에 코드가 그 책의 id와 서명을 적는다. 책 표시는 이용자 문장과 따로 두고, 다음 턴에 LLM에게 코드의 안내 메시지로 간다. 고른 책만 보낸 턴은 문장이 비고 책 표시만 있는 이용자 행 하나를 저장한다. tool 입력과 결과, 추론 내용, 검사를 통과하지 못한 답은 저장하지 않는다.

#### Scenario: 메시지 행
- **WHEN** tool을 거친 턴이 끝나면
- **THEN** 그 턴의 메시지 행은 이용자 문장과 최종 답 두 개뿐이다

#### Scenario: 고른 책만 보낸 턴
- **WHEN** 고른 책만 보낸 턴이 끝나면
- **THEN** 그 턴의 메시지 행은 문장이 비고 책 표시에 고른 책의 id와 서명이 있는 이용자 행 하나다

#### Scenario: 다음 턴의 문맥
- **WHEN** 고른 책만 보낸 뒤 `비슷한 거 있어요?`를 보내면
- **THEN** LLM이 받은 이전 대화에 고른 책의 id와 서명이 안내 메시지로 있고, 이용자 문장 목록에는 `비슷한 거 있어요?`만 있다

## ADDED Requirements

### Requirement: 고른 책 턴의 상한
고른 책만 보낸 턴은 턴 상한에 SHALL 들어가고, LLM을 부르지 않으므로 일일 실행 상한에는 들어가지 않는다. 동시 요청 금지와 세션 만료는 다른 턴과 같다.

#### Scenario: 턴 상한
- **WHEN** 상한보다 하나 적게 턴을 쓴 세션에 고른 책만 보낸 뒤 문장을 보내면
- **THEN** 409를 돌려준다

#### Scenario: 일일 실행 상한
- **WHEN** 일일 실행 상한에 이른 기관에서 고른 책만 보내면
- **THEN** 200으로 응답하고 `found` 사건이 나간다
