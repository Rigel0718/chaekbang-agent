## ADDED Requirements

### Requirement: 제품 경로의 주제로 찾기
AI 사서의 소장 도서 검색은 낱말이 있으면 주제로 찾기의 기본 설정으로 순위를 SHALL 만들고 앞의 10권을 낸다. 제품 경로는 순위 설정을 따로 고르지 않는다. 벡터 질의는 기본 설정의 벡터 질의 입력을 따르고, 이용자 문장은 이 경로에 넘기지 않는다. 낱말이 없으면 키워드 없는 둘러보기와 같다.

#### Scenario: 기본 설정과 같은 순서
- **WHEN** 같은 기관, 같은 낱말로 제품 경로와 기본 설정의 주제로 찾기를 부르면
- **THEN** 제품 경로의 결과는 주제로 찾기 결과의 앞 10권과 같은 책, 같은 순서다

#### Scenario: 낱말 없음
- **WHEN** 낱말 없이 제품 경로를 부르면
- **THEN** 결과가 키워드 없는 둘러보기 결과와 같고 인코더를 부르지 않는다

#### Scenario: 결과 수
- **WHEN** 키워드나 벡터로 맞는 추천 가능한 책이 30권인 기관에서 부르면
- **THEN** 10권이 나온다

### Requirement: 키워드 순위로 내려가기
제품 경로는 질의 인코딩이 실패하거나, 시간 제한을 넘거나, 서버가 설정과 다른 모델을 제공하거나, 인코더가 없으면 키워드 순위만으로 결과를 MUST 만든다. 이때 결과는 같은 낱말의 키워드 검색과 같은 책, 같은 순서다. 결과 모양은 바뀌지 않고, 로그에는 실패 종류만 남기며 낱말과 이용자 문장을 남기지 않는다.

#### Scenario: 서버가 꺼짐
- **WHEN** 임베딩 서버에 닿지 않는 상태에서 낱말 `공룡`으로 부르면
- **THEN** 결과가 낱말 `공룡`의 키워드 검색 결과와 같은 책, 같은 순서다

#### Scenario: 시간 제한
- **WHEN** 질의 인코딩이 시간 제한보다 오래 걸리면
- **THEN** 시간 제한이 지난 뒤 키워드 순위로 결과가 나온다

#### Scenario: 다른 모델
- **WHEN** 임베딩 서버가 설정과 다른 모델 이름을 알리면
- **THEN** 벡터 순위를 쓰지 않고 키워드 순위로 결과가 나온다

#### Scenario: 로그
- **WHEN** 인코딩이 실패해 내려가면
- **THEN** 로그에 실패 종류가 있고 낱말은 없다

### Requirement: 질의 인코딩 쉬기
질의 인코딩이 실패하면 시스템은 정한 시간(기본 30초) 동안 임베딩 서버를 MUST NOT 부르고 그동안의 요청은 바로 키워드 순위로 내려간다. 그 시간이 지나면 다시 부른다. 처음 쓸 때 서버의 모델과 입력 한도를 한 번 확인하고, 확인에 성공하면 다시 확인하지 않는다.

#### Scenario: 쉬는 동안
- **WHEN** 인코딩이 한 번 실패한 뒤 10초 안에 다시 부르면
- **THEN** 임베딩 서버에 요청이 가지 않고 키워드 순위로 결과가 나온다

#### Scenario: 쉬기가 끝남
- **WHEN** 인코딩이 실패하고 30초가 지난 뒤 다시 부르면
- **THEN** 임베딩 서버에 요청이 간다

#### Scenario: 모델 확인 한 번
- **WHEN** 서버가 정상일 때 제품 경로를 세 번 부르면
- **THEN** 모델 확인 요청은 한 번이다

### Requirement: 키워드 근거 없음 표시
제품 경로는 낱말이 있는데 키워드 순위가 비고 벡터 순위로만 결과가 나오면 결과에 키워드 근거가 없다는 표시를 SHALL 붙인다. 키워드 순위에 한 권이라도 있으면 표시하지 않는다. 결과를 비우는 유사도 문턱은 두지 않는다.

#### Scenario: 낱말이 맞는 책 없음
- **WHEN** 어느 책에도 들어 있지 않은 낱말로 부르고 벡터 순위에 책이 있으면
- **THEN** 결과에 벡터 순위의 책이 있고 키워드 근거 없음 표시가 있다

#### Scenario: 낱말이 맞는 책 있음
- **WHEN** 한 권에만 들어 있는 낱말로 부르면
- **THEN** 키워드 근거 없음 표시가 없다

#### Scenario: 내려간 결과
- **WHEN** 인코딩이 실패한 상태에서 어느 책에도 들어 있지 않은 낱말로 부르면
- **THEN** 결과가 비어 있고 키워드 근거 없음 표시가 없다

### Requirement: 제품 경로의 범위
제품 경로는 그 기관의 추천 가능한 책 중 부르는 쪽이 넘긴 조건 안의 책만 MUST 낸다. 벡터 순위로 내려가거나 키워드 근거가 없어도 같다.

#### Scenario: 다른 기관의 벡터 1위
- **WHEN** 질의 벡터와 가장 가까운 책이 B 기관에만 있을 때 A 기관에서 부르면
- **THEN** 그 책은 결과에 없다

#### Scenario: 조건 밖의 벡터 1위
- **WHEN** 벡터 1위가 일반 도서일 때 어린이 도서 조건을 넘겨 부르면
- **THEN** 결과는 모두 어린이 도서다
