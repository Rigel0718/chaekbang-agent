## ADDED Requirements

### Requirement: 실행 값 주입
실행을 시작한 코드는 이름과 값의 묶음(실행 값)을 넘길 수 있고, 실행기는 그 값을 tool 실행 함수에 읽기 전용으로 SHALL 그대로 전한다. 실행기는 값의 뜻을 모른다. LLM은 실행 값을 정하거나 바꿀 수 없고, 실행 값은 실행 기록에 남기지 않는다. 넘기지 않으면 빈 묶음이다.

#### Scenario: 실행 값 전달
- **WHEN** 실행 값 `{"session_book_ids": [3, 5]}`로 실행을 시작해 tool이 호출되면
- **THEN** 실행 함수는 같은 실행 값을 받는다

#### Scenario: LLM이 같은 이름을 입력에 넣음
- **WHEN** LLM이 tool 입력에 `session_book_ids`를 넣어 부르면
- **THEN** 정의되지 않은 입력으로 거부되고 실행 함수는 불리지 않는다

#### Scenario: 실행 기록에 없음
- **WHEN** 실행 값을 넘긴 실행이 끝난 뒤 실행 기록을 보면
- **THEN** 실행과 단계 기록 어디에도 실행 값이 없다

#### Scenario: 넘기지 않은 실행
- **WHEN** 실행 값 없이 실행을 시작해 tool이 호출되면
- **THEN** 실행 함수는 빈 실행 값을 받는다
