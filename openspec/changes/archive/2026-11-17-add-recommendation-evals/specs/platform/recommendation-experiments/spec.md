## ADDED Requirements

### Requirement: 실제 LLM 낱말로 주제 실행
실험 틀은 주제 질의 세트의 사람이 쓴 낱말 대신, 대화 추천 평가 실행이 받은 실제 LLM 낱말로 주제 변형을 SHALL 돌린다. 항목마다 마지막 턴의 첫 검색 tool 호출의 낱말을 쓴다. 검색 tool을 부르지 않은 항목은 빼고 그 수를 요약에 적는다. 결과는 같은 라벨로 채점하고 같은 짝 비교를 낸다.

#### Scenario: 낱말 바꾸기
- **WHEN** 대화 평가 결과에서 `t01`의 첫 검색 낱말이 `공룡`, `그림책`인 실행을 주고 낱말 입력 변형을 가짜 인코더로 돌리면
- **THEN** `t01`의 키워드 검색과 인코더가 받은 질의가 그 두 낱말이다

#### Scenario: 검색 없는 항목
- **WHEN** 대화 평가 결과에 검색 tool을 부르지 않은 주제 항목이 하나 있으면
- **THEN** 그 항목은 실행에서 빠지고 요약에 빠진 항목 수 1이 있다
