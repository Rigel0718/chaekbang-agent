# 도서관 정보나루 API: 나중에 확장할 아이디어

지금 계획에는 없는 것들이다. 쓸 때가 되면 change로 제안한다. 번호는 `data4library.md`의 API 번호다.

| 아이디어 | API | 메모 |
| --- | --- | --- |
| 최근 기록 추천의 후보 | 4·5 `recommandList` | ISBN을 최대 5개까지 한 번에 넣을 수 있다. 결과 중 소장 도서만 남기면 최근 기록 신호로 쓸 수 있다 |
| 주제로 찾기 보강 | 7 `keywordList` | 책마다 키워드가 가중치와 함께 최대 50개 온다. 키워드 검색이나 임베딩 텍스트에 넣어 실험해 볼 수 있다. 저자명·출판사명이 섞여 오니 걸러야 한다 |
| ISBN 없는 책 연결 | 16 `srchBooks` | 서명·저자로 찾아 공식 서지 후보를 만든다. 자동으로 연결하지 않고 관리자가 확인한다 |
| 보충 구매 요청서 초안 | 3 `loanItemSrch` | 연령·KDC로 거른 인기 도서 중 소장하지 않은 책을 후보로 둔다. 확정은 승인 흐름을 거친다 |
| 우리 동네 인기 | 9 `loanItemSrchByLib` | 기관 주소의 지역 코드(`region`·`dtl_region`)로 조회한다. 전국 인기보다 작은도서관에 가깝다 |
| "요즘 많이 빌리는 책" 큐레이션 | 12 `hotTrend` | 대출 급상승 도서를 큐레이션 초안의 재료로 쓴다 |
| 이달의 주제 큐레이션 | 17 `monthlyKeywords` | 시즌 큐레이션(2단계)의 주제 후보 |
| 희망도서 안내 | 13 `libSrchByBook`, 11 `bookExist` | 우리 도서관에 없는 책을 근처 공공도서관이 가지고 있는지, 대출 가능한지(전날 기준) 알려 준다 |
| 이 책을 많이 읽는 연령대 | 6 `srchDtlList`(`loaninfoYN=Y`), 8 `loanGrps` | 카드에 참고로만 보여 준다. 어린이 도서 분류 근거로 쓰지 않는다(분류는 코드 규칙으로 정한다) |

호출 수와 이용 조건(일일 한도, 저장·재배포)은 쓸 때마다 다시 확인한다. 표지(`bookImageURL`)는 화면 표시에만 쓴다.
